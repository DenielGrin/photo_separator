# Облачный pilot — 29.10.2026

После получения пользователем двух ключей выполнено по 20 image-запросов к прямым API DeepSeek и OpenAI. Это **платные** прогоны; наличие ключей этих сервисов не открывает OpenRouter free. Оба ключа прошли read-only проверку `/models`, выбранные модели присутствовали в списках. Повторных inference-вызовов после получения метрик не делалось.

## Протокол

Те же URL, SHA-256 исходных байтов, нормализация Pillow, промпт `restaurant-cover-v1`, политика и пороги, что у локальных Qwen. Датасет `labeled-pilot.json` v2: 20 фото, 8 keep / 8 reject / 4 review. Метки модели не получали. Два ресторана, до двух одновременных запросов на ресторан. GPT: Responses API, `gpt-6-luna`, low reasoning. DeepSeek: chat completions, `deepseek-flash`, thinking disabled. Ошибка схемы приводит к review, а не к принятию.

Разметку предварительно составил агент; независимая человеческая проверка обязательна. Исправление одного локального label v1→v2 предшествовало облачному прогону. Локальные прогнозы пересчитаны на v2 без изменения ответов. Это сравнение конкретного промпта и адаптеров, не модели в оптимально настроенной конфигурации.

| Метрика | GPT-6 Luna | DeepSeek Flash |
|---|---|---|
| Фото / успешные оценки | 20 / 20 | 20 / 16 |
| Совпадение решений с label | 80% | 55% (включая ошибки как review) |
| Приняты / пригодны по label | 6 / 5 | 3 / 3 |
| Чистота обложек | 83,3% | 100% на трёх кадрах; неполный прогон |
| Найдено хороших из 8 | 5 (62,5%) | 3 (37,5%) |
| Ошибочные принятия | 1 | 0 |
| Ошибочные отказы хорошим | 2 | 3 |
| Review | 4 | 10 |
| ≥3 обложки в ресторанах | 1 из 2 | 0 из 2 |
| Время Cremat / Райский Сад | 55,736 / 28,668 с | 11,613 / 11,596 с |
| Оценка расхода / 20 фото | $0,0050702 | ≥$0,0073386 |

GPT пропустил в обложку Cremat кадр с человеком (фото index 0, label review), у двух подходящих фото Райского Сада поставил оценку ниже порога. DeepSeek не дал валидной оценки четырём фото: Cremat indices 2,7,8; Райский Сад index 5. Строгий парсер намеренно не сохраняет сырое тело ответа, поэтому нельзя установить, было ли причиной отсутствие JSON или несовпадение конкретного поля схемы. Не следует приписывать эти четыре случая ошибке визуального распознавания.

## Стоимость и ограничения

Оценка рассчитана по usage успешных ответов: GPT input/output $0.10/$0.50 за 1M токенов, DeepSeek настроен по обычному тарифу $0.30/$1.20 (off-peak $0.15/$0.60 может уменьшить счёт). В итоговую стоимость не включены инфраструктура, налоги и неизвестные списания за четыре невалидных ответа DeepSeek: текущий адаптер при ошибке парсинга не сохраняет usage. Проверка `/models` не является image-inference. Окончательный расход проверяется в кабинете провайдера.

[OpenAI модель](https://developers.openai.com/api/docs/models/gpt-6-luna), [тарифы](https://developers.openai.com/api/docs/pricing), [DeepSeek тарифы](https://api-docs.deepseek.com/quick_start/pricing/).

## Бесплатные модели

Обновлён публичный каталог: 8 моделей с image input, суффиксом `:free` и нулевыми ценами prompt/completion/image/request. Четыре поддерживают принудительный JSON, четыре проверяются prompt-only режимом. Полный [план](free-cloud-plan-2026-10-29.json) получен без ключа, с **нулём inference-вызовов**. Ключ OpenRouter не предоставлен. Ни качество, ни фактическая доступность восьми endpoints для аккаунта пока не измерены.

`benchmark_free.py` ограничивает число вызовов на запуск, сохраняет каждый ответ и счётчик попыток до отправки; успешные ответы повторно не отправляет при совпадении подписи эксперимента и digest изображения. Это не гарантия exactly-once billing: при аварии после отправки запроса и до checkpoint неизвестный ответ может потребовать повторной отправки. Убедиться в квоте до следующего запуска. Квота, прерывание и смена датасета покрыты тестами; реальные free-inference пока не проверены.

## Обращение с ключами

Ключи передавались только в память отдельного процесса через скрытый терминальный ввод, без аргументов командной строки и без `.env`. Процесс завершён; временные ссылки на значения очищены, временный runner удалён. Ключей нет в исходниках, отчётах, README и Git. История исходного чата и инструмента ввода не может быть удалена агентом; пользователь должен отозвать опубликованные в чате ключи в кабинетах провайдеров.

## Вывод для продукта

Ни один вариант не подтвердил достаточную надёжность для автоматической публикации. Qwen 2B выше по чистоте (87,5%), Qwen 8B по полноте (100%) и accuracy (90%); GPT дешевле одного цента на этот пилот, но хуже по полноте. DeepSeek требует отдельной настройки контракта ответа и нового заранее зафиксированного прогона. Разница нескольких кадров на выборке 20 недостаточна для уверенного выбора победителя. Следующий шаг — бесплатный облачный прогон и независимая разметка большего корпуса, с главным критерием precision обложек и достаточным покрытием ресторанов.
